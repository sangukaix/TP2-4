## 사용 안내

PPTX의 발표자 노트에 각 장의 설명과 근거 파일을 기록했습니다. 표·차트·구조도·텍스트를 직접 수정할 수 있습니다. PDF는 같은 자료의 열람용입니다.

로컬 Gemma 구성과 현재 AWS OpenAI-only 구성을 구분했습니다. ML 평가와 RAG 현황은 확인한 로컬 산출물 기준입니다. 기획 목표와 견적은 계획 가정이며 실제 관광사업 성과로 제시하지 않습니다. 저장된 화면 캡처에는 과거 UI가 포함되어 있으므로 실시간 시연은 배포 사이트에서 진행합니다.

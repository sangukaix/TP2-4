# 최종 목차·정렬·타이포그래피

- 최종 파일: deliverables/제주시_기획서_최종.pptx
- 목차: 회색 그라데이션의 작은 2단 목록. '0. 개요'. 모든 본문 소제목 왼쪽 정렬.
- 4장: 제공 SPICUS 3/28장과 fontScheme 분석. 영문 Century Gothic, 한글 맑은 고딕. 제목 26pt/사례 제목 14pt/본문 11pt/출처 9pt. 캔버스는 기존 16:9 유지.
- 표지 출처 문구는 메모에 보존하고 장소명만 표시. 파란 배경 높이는 줄 수에 따라 조정. 마지막 장 반복 제목 삭제.
- 웹 디자인 탐색: https://slidesgo.com/minimalist (디자인 방향만 참고, 외부 템플릿 다운로드/복제 없음).
- render/: PowerPoint 15장 렌더. audit.json: 12개 제목 왼쪽 정렬, 공식 수치/차트/표 보존, 요청 문구만 변경, 1/2줄 캡션 42/60px 검증.
- validation.json: 패키지/기하/차트·내장 Excel/Artifact Tool 검수 통과.
- build.py는 네트워크를 차단하고 저장 보고서 불변을 확인. LLM/유료 호출 없음.

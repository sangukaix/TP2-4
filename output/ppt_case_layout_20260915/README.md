# 사례 카드·실적 여백·지역 시설 사진

- 최종 파일: deliverables/제주시_기획서_최종_v3.pptx
- 4장 안내 문장 제거, 카드 상향, 글자 확대(제목 17pt/본문 15pt/번호 20pt).
- 5장 사례명/내용 상향, 7장 중앙 설명/여백 조정, 마지막 장은 장소명만 표기.
- 8장 국립제주박물관/제주목 관아: 실제 사업 참여처 확정이 아닌 적용 공간 예시. 한국관광공사 API 사진/출처 표시.
- collect_photos.py: 기존 키로 두 명소 검색. 키/인증 URL은 로그나 문서에 출력하지 않음. 공통 렌더는 저장 메타데이터와 검증 이미지 캐시 사용.
- 참고 디자인 https://slidesgo.com/theme/case-study-infographics-minimalist 및 사용자 SPICUS/첨부 이미지. 외부 템플릿 복제 없음.
- audit.json: 지정 5장만 변경, 기존 차트/표 데이터 보존, 실제 PowerPoint 렌더 확인.
- validation-v3.json: 최종 패키지/기하/차트·Excel/Artifact Tool 검수. 앞선 validation.json은 중간본 기록.
- LLM/유료 호출 없음.

# 확정 PPT 공통 양식

- 확정 버전: `pptx-v60-approved-regional-template`
- 적용 범위: 모든 시군구의 PowerPoint 다운로드. 지역 수치·사례·사진은 각 보고서 데이터로 구성한다.
- 생성 경로: `main.py` → `proposal_presentation.py` → `proposal_presentation_v4.py` → `proposal_final_polish.py`.
- 섹션 헤딩 17.3pt, 페이지 제목 30pt, 모두 왼쪽 정렬. 목차 번호와 항목 20pt.
- 전망 페이지는 기존 사진·외곽 카드 크기를 유지하며 내부에 합계, 비교 차트, 높음/낮음 배지를 표시한다.
- 전망 다음에 제안 사업 소개. 적용 사례 카드 옅은 하늘색, 후보 카드는 흰색.
- KPI 설명 16pt, 계산 설명 15pt, 목표 숫자 27pt. 운영 규모·월별 목표·파이프라인은 승인된 공통 배치 사용.
- 사진 설명은 사진 내부 파란 배경과 가운데 정렬을 사용한다. 표지·마지막 페이지의 승인된 예외를 유지한다.
- 본문 길이에 따라 공통 줄바꿈·맞춤 규칙을 적용한다. 출처 수와 사례 성과 자료 유무에 따른 내용 차이는 허용한다.
- 양식 변경 시 렌더 버전을 함께 갱신한다. 문서 캐시는 형식과 렌더 버전으로 확인된다.
